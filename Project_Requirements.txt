============================================================
1. PROJECT OBJECTIVE
============================================================

Develop a modern, responsive real estate website for
Shivrai Group with a fully functional administration panel.

The platform must allow:

1. Visitors to explore real estate developments.
2. Visitors to view individual project information.
3. Visitors to browse project images and galleries.
4. Visitors to submit enquiries.
5. Administrators to manage project information.
6. Administrators to upload and organize media.
7. Administrators to manage customer enquiries.
8. Administrators to monitor project views.
9. Website content to be maintained through the backend.

The final website should have a premium architectural
visual identity, responsive layouts, and reliable APIs.

3.5 CONTACT PAGE
------------------------------------------------------------

FORM FIELDS:

1. Full name
2. Email address
3. Phone number
4. Subject (optional)
5. Message

VALIDATION:

- Name: minimum 2 characters
- Email: valid email format
- Phone: 10–15 digits, optional leading +
- Message: required
- Subject: optional

SUBMISSION PROCESS:

1. Validate form.
2. Disable button during submission.
3. Send data to backend.
4. Store enquiry in MongoDB.
5. Display success confirmation.
6. Show redirect message.
7. Wait 3 seconds.
8. Redirect to homepage.

ERROR HANDLING:

- Display submission errors.
- Do not redirect on failure.
- Prevent duplicate submissions.
